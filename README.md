## Seções

1. **Hero** — Apresentação, chamada e ilustração de circuito minimalista
2. **Sobre** — Quem sou, objetivos, jornada e forma de aprender
3. **Stack** — Frontend, Backend, Ferramentas e tecnologias em estudo
4. **Projetos** — Cards em estilo cartaz editorial
5. **Jornada** — Timeline conectada pela linha principal, do início aos objetivos
6. **GitHub** — Repositórios, projetos, commits e tecnologias mais usadas
7. **Contato** — Formulário e links diretos
8. **Footer** — Frase de encerramento e fim da linha

## Tecnologias do projeto (protótipo atual)

Este repositório contém um protótipo estático em **HTML + CSS + JavaScript puro** (`index.html`), usado como referência visual e funcional do design.

- SVG animado por scroll (linha contínua)
- Scroll reveal com `IntersectionObserver`
- Layout responsivo (desktop, tablet e mobile)

## Como visualizar o protótipo

Não é necessário instalar nada — basta abrir o arquivo `index.html` diretamente no navegador:

```bash
open index.html
```

ou, no Windows/Linux:

```bash
xdg-open index.html   
start index.html       
```
